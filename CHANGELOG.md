# Changelog

## 0.1.0 — 2026-10-03

- Add Linux systemd, container, listener, project, proxy-route, and firewall-evidence discovery with explicit partial-source diagnostics.
- Add a loopback-only embedded dashboard with owner-token authentication and explicitly configured private Tailscale proxy identity.
- Add actor-bound, expiring, typed lifecycle approvals and durable private audit records.
- Add a peer-checked privileged Unix broker with root-owned service/container allowlists.
- Add interface-specific nftables INPUT policy previews, protected management ports, runtime-derived Tailscale peer API exceptions, durable pending state, and automatic rollback.
- Add Linux release installation, systemd user/root service installation, private XDG configuration/state, and persisted local binding across restarts.
- Prioritize explicit project roots and scan breadth-first so one deep directory tree does not hide neighboring projects before the traversal cap.
- Preserve multicall executable invocation names and exclude uninstantiated systemd templates from runtime property batches.
- Validate root process/executable identity for automatic SSH exceptions and pin container discovery/control to matching local Unix endpoints.
